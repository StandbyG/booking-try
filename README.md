# Booking Try

Motor de reservas/turnos para negocios con recursos limitados (canchas, consultorios,
salones de belleza, etc), con prevención de doble-reserva bajo concurrencia real.
Proyecto de portafolio full-stack.

- **[`backend/`](backend/README.md)** — API REST en Java 21 + Spring Boot 3, JWT,
  PostgreSQL, Flyway, y tests de integración con Testcontainers. Documentación
  completa (arquitectura, decisiones de diseño, cómo correrlo) en su README.
- **[`frontend/`](frontend/README.md)** — pendiente.
